# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: static HTML, CSS, and JavaScript chosen for a fast, dependency-free GitHub Pages deployment.

## Users

Potential collaborators, clients, and hiring managers evaluating a creative technologist's work and deciding whether to start a conversation. All personal identity and project details are intentionally placeholder content until supplied by the owner.

## Product Purpose

A personal portfolio that introduces the maker, frames a selected body of work, and creates a clear path to make contact.

## Positioning

An editorial, product-minded portfolio that makes the work feel considered before the visitor reads a résumé or opens an external profile.

## Operating Context

Visitors arrive on desktop or mobile from a shared link, search result, résumé, or social profile. The site is a static GitHub Pages deployment and must remain usable without a backend.

## Capabilities and Constraints

- A single static landing page with responsive navigation, a comprehensive about section drawn from the resume, selected-work previews, and contact links.
- No external runtime dependencies or backend services.
- The resume is published at the repository root as a downloadable PDF, so any claim on the page must stay traceable to that file.
- GitHub Pages-compatible paths and assets only.

## Evidence on Hand

A supplied `Resume.pdf` is the approved source for all identity, education, experience, skills, and certificate claims. The "About me" section is a restatement of that document, not invented content. Project case studies, photography, and testimonials remain unapproved; the selected-work entries stay high level until the owner supplies detail. Contact endpoints are the addresses already published in the resume.

## Product Principles

- Let the work lead; interface supports rather than competes with it.
- Make a confident first impression while preserving clarity and accessibility.
- Keep every future content replacement simple and local.
- Prefer speed, restraint, and a tactile sense of craft over decorative excess.
