Context

Voice cloning moved from research demo to consumer tool while I was studying, and detection fell behind generation. The problem is a classification problem wearing an audio costume: given a clip, decide whether a human or a model produced it.

My final-year project at UiTM took that on directly — start from raw speech, extract features that carry the fingerprints of synthesis, and compare the two dominant ways of modelling them.

Approach

Feature extraction

  • MFCCs — the compact cepstral summary of short-term power spectra that audio classification has trusted for decades.
  • Spectrograms — time-frequency images of the signal, which lets visual-pattern machinery do the work.
  • Extraction lives in its own notebook so every architecture is fed the same inputs.

Two architecture families

  • CNNs read the spectrogram as an image and learn local patterns — onsets, harmonics, the smudge of vocoder artefacts.
  • RNNs with LSTM and GRU cells read the clip as a sequence, which matches how speech unfolds over time.
  • Runs were carried out on GPU where the sequence models needed it.

Experiment tracking

  • Every configuration — feature set, architecture, data reduction — is preserved as its own notebook in Experiments/, so results stay traceable to the exact setup that produced them rather than being overwritten by the next run.

Outcome

  • A completed final-year project comparing CNN and RNN approaches across both feature types, written up as FYP_paper.pdf in the repository.
  • A reusable extraction and training setup — the same feature pipeline feeds either architecture, so the comparison isolates the model rather than the preprocessing.
  • The habit that outlasted the project: keep every experiment as a reproducible artefact instead of a lost cell output.
View repository Read the paper

Notes & limits

Detector accuracy degrades against generators the model never saw during training, and synthetic speech keeps improving — this is an arms race, not a solved problem. The paper records where each architecture held up and where it didn't.
